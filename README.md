## Установка и запуск

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/PankofID/ToDo-Bot.git
cd ToDo-Bot
```
---

### Шаг 2. Создание виртуального окружения

```bash
python -m venv venv
venv\Scripts\activate
```
---

### Шаг 3. Установка зависимостей

```bash
pip install -r requirements.txt
```
---

### Шаг 4. Получение токена бота

1. Откройте Telegram и найдите **[@BotFather](https://t.me/BotFather)**.
2. Создайте бота
3. Получите токен бота
4. 
---

### Шаг 5. Настройка `.env`

В корне проекта создайте файл `.env` и вставьте в него свой токен:

```env
BOT_TOKEN=ВАШ_ТОКЕН
```
---

### Шаг 6. Запуск бота

```bash
python main.py
```

В терминале должно появиться:

```text
Start...
```

Если ошибок нет — откройте своего бота в Telegram и отправьте `/start`.
